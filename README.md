# ASH · PETS3 笔试练习

按用户提供的《考试内容及形式》《评分标准》及2025版三级样卷制作的9套原创练习网站。当前实际题库数量以 `public/papers/index.json` 为准。

## 规则

- 笔试100分钟，不含口语。
- 听力A：5段约200词材料，20道四选一，播放一次。
- 听力B：1段约200词独白，5个信息填空，每空1词或数字，播放两次。
- 阅读A：3篇约350词，15道四选一。
- 阅读B：约350词、5段主旨匹配，7选5。
- 阅读C：200—250词，15选10。
- 写作：图表或图片议论文，约120词，1题。

样卷原录音分析：时长1246.374秒。A每组预读20秒、检查40秒；B预读25秒，首遍后检查30秒，再听一遍，检查20秒。练习整卷录音另加入纸笔规则要求的2分钟誊写时间。

## 评分边界

客观题显示正确题数。听力B自动匹配是复核起点，不等同人工综合评分。作文显示词数、思路和范文，导出后交教师或ASH依照五档评分标准批改。未获得官方等值换算表，不生成官方总分或合格结论。

网页为自学工具，答案位于静态题库中，不适合作为保密考试系统。作答保存在浏览器本地，导出可备份。模考不要刷新页面；刷新会中断连续录音。

## 音频

`public/audio`中的原创录音为合成语音，使用英式男/女声。整卷带预读、检查、重复和誊写停顿；分段版供重听。用户原始PDF、样卷音频、准考证和已作答文件不在发布目录中。

OpenAI也提供语音生成API，可离线生成MP3后替换静态音频；当前实现不需要网页访问API，不把密钥放入前端。

## 构建

使用Node 22.22.0（Windows Node 24构建结束时出现原生退出断言）。

```
npm ci
python content/build_bank.py
python content/validate.py
npm run build
```

静态输出：`dist/client`。GitHub Pages路径由 `GITHUB_ACTIONS` 环境变量设置为 `/pets3-practice`。

来源：用户提供PDF；[教育考试院大纲启用说明](https://pets.neea.edu.cn/html1/folder/16093/1175-1.htm)。题目中的非真实统计图表明确标记为模拟数据。
